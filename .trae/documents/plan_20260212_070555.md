## 修改问答接口请求方法

### 问题
- 当前 `qa.ts` 文件中使用的是 POST 请求方法
- 用户指出实际接口是 GET 请求

### 修改方案

1. **修改 API 接口封装文件**
   - 文件：`src/api/qa.ts`
   - 将 `request.post` 改为 `request.get`
   - 调整参数传递方式，从请求体改为查询参数

2. **修改调用方式**
   - 文件：`src/views/Evaluation.vue`
   - 确保调用方式与接口变更一致

### 技术实现
- GET 请求参数通过 URL 查询字符串传递
- 保持返回类型和处理逻辑不变
- 确保 TypeScript 类型定义正确

### 影响范围
- 仅影响自动评估功能中的问答接口调用
- 不影响其他功能模块
